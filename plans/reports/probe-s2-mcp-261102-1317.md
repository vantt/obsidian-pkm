# Bài thử S2: MCP Rust bắt tay với Claude (R02)

Ngày: 2026-11-02. Phase: [phase-03-spec-probe-mcp.md](../261102-0535-rust-core-port-master/phase-03-spec-probe-mcp.md). Repo đặc tả ở sha ghim `5a3eb2f`.

## 1. Kết quả

- **Q4 đã chốt: JSON-RPC stdio tự viết**, đồng bộ, chỉ `serde_json`. Lý do và bằng chứng ghi ở [DECISIONS.md](../../docs/DECISIONS.md) mục Q4; số đo ở mục 4 dưới đây.
- Claude Code 2.1.316 bắt tay và gọi được tool `find` của **cả hai** server thử (bản tự viết và bản `rmcp`). Bản ghi phiên ở mục 5.
- Phiên bản giao thức: Python trả lại đúng bản client xin nếu thuộc `('2025-06-18', '2025-03-26', '2024-11-05')`, không thì `2025-06-18`. Cả hai bản Rust làm giống hệt (Claude Code xin `2025-11-25`, cả ba server cùng trả `2025-06-18`).
- **Còn chờ user:** chạy thử Claude Desktop trên Windows (mục 6). Phase giữ `in-progress` tới khi user báo kết quả.

## 2. Python đang trả gì (`scripts/kg/mcp_server.py` ở `5a3eb2f`)

- `PROTOCOLS = ('2025-06-18', '2025-03-26', '2024-11-05')`, `serverInfo = {"name": "kg", "version": "0.1.0"}`, `capabilities = {"tools": {"listChanged": false}}`.
- `instructions` ghép từ vault (mô tả, loại note, quan hệ, lớp cạnh, link Obsidian, OHS). Bài thử dùng một bản ngắn cố định có tiếng Việt, ngoặc kép, backtick và xuống dòng để kiểm câu chữ đi qua nguyên vẹn; ghép thật thuộc R10.
- Tầng JSON-RPC tự viết: `initialize`, `ping`, `tools/list`, `tools/call`; `resources/list`, `prompts/list`, `resources/templates/list` trả rỗng; phương thức lạ `-32601 "method not found: <m>"`; dòng không phải JSON `-32700` với `id: null`; batch trả mảng; notification (không `id` hoặc `id: null`) không trả lời; không chặn request trước `initialize`.
- `tools/call` trả `{"content":[{"type":"text","text":<JSON gọn>}],"isError":<bool>}`, lỗi là object có `error` và nhiều nhất hai khoá.

## 3. Server thử (`probes/s2-mcp/`)

Crate đứng riêng (có `[workspace]` của mình), không là member của workspace gốc.

| File | Vai trò |
|---|---|
| `src/lib.rs` | Phần chung: `PROTOCOLS`, `negotiate`, `instructions`, khai báo `find` (chép nguyên văn mô tả và schema của Python), chạy `find` trên thư mục vault (khớp mọi từ, bỏ dấu và `đ` như `vault.fold`, lọc `type:` ở frontmatter, bỏ thư mục ẩn), `compact` như Python |
| `src/bin/hand.rs` → `s2-hand` | JSON-RPC theo dòng tự viết, chép `Server.handle` / `Server.serve` của Python |
| `src/bin/with_rmcp.rs` → `s2-rmcp` | Cùng tool qua `rmcp` 3.8.0 + `tokio` (feature `rmcp`) |
| `tests/stdio_session.rs` | Chạy binary như client: bắt tay, `tools/list` so **chuỗi** mục `find` với `tests/python-find-tool.json` (xuất từ `tool_defs()` của Python ở sha ghim), gọi tool; các cạnh giao thức của Python (parse error, batch, phương thức lạ, phiên bản cũ) |

`find` của bài thử là bản rút gọn chạy thật trên file (không đọc alias, không index); `find` đúng nghĩa thuộc R08.

Chạy:

```bash
cd probes/s2-mcp
cargo test                    # chỉ s2-hand
cargo test --features rmcp    # cả s2-rmcp
cargo build --release --features rmcp
```

Kiểm: `cargo fmt`, `cargo clippy --all-targets [--features rmcp] -- -D warnings` sạch; `cargo test --features rmcp`: 4 test đơn vị + 3 test phiên qua. Workspace gốc: `cargo fmt --all --check`, `cargo clippy --workspace --all-targets --locked -- -D warnings`, `cargo test --workspace --locked` vẫn qua.

## 4. So hai cách

Linux x86_64, toolchain 1.97.1, `--release` với `strip = true`, máy 24 nhân.

| | `s2-hand` (tự viết) | `s2-rmcp` (`rmcp` 3.8.0) |
|---|---|---|
| Binary | 697.752 B (0,68 MB) | 2.926.000 B (2,79 MB) |
| Crate phụ thuộc (`cargo tree -e normal`, kể cả chính nó) | 12 | 56 (`tokio`, `futures`, `schemars`, `chrono`, `tracing`, `uuid`, `thiserror`, …) |
| Build release từ sạch | 2,5 s | 16,5 s |
| Async runtime | Không | Bắt buộc `tokio` (`rt`, `io-std`, và `time`: thiếu `enable_time` thì panic khi nhận request đầu) |
| Câu chữ `instructions`, mô tả, schema | Đủ | Đủ (`Tool` nhận JSON tuỳ ý; `preserve_order` của `serde_json` giữ thứ tự khoá cho cả `rmcp`) |
| Phiên bản giao thức như Python | Có | Có, phải ghi đè `supported_protocol_versions` |

Khác Python ở tầng giao thức (cùng một phiên gửi tới ba server; Python chạy `python3 scripts/kg VAULT mcp --db <tạm> --refresh-every -1` ở sha ghim, script để ngoài repo):

| Tình huống | Python | `s2-hand` | `s2-rmcp` |
|---|---|---|---|
| Phương thức lạ `nope/x` | `-32601 "method not found: nope/x"` | giống | `-32601 "nope/x"` |
| Dòng không phải JSON | `-32700 "parse error"`, `id: null` | giống | không trả lời |
| Batch hai `ping` | mảng hai kết quả | giống | `-32600 "Invalid request"`, không có `id` |
| `tools/list` trước `initialize` | trả danh sách tool | giống | `-32602` đòi `_meta` của giao thức 2026-07-28 |
| `server/discover` (Claude Code gửi đầu tiên) | `-32601` | giống | `-32022 Unsupported protocol version` |
| `initialize` 2024-11-05 / 2025-11-25 | trả 2024-11-05 / 2025-06-18 | giống | giống |
| `tools/list`, `tools/call` | — | giống từng byte của nhau | giống từng byte của nhau |

Không chỗ nào ở trên làm hỏng Claude Code. Nhưng bộ so khớp so cả tầng MCP (PRD mục 8, rủi ro "mô tả tool MCP lệch câu chữ"), và với `rmcp` muốn khớp thì phải viết thêm handler riêng cho từng chỗ, có chỗ (parse error, batch) nằm trong tầng transport của `rmcp`, không ghi đè được từ `ServerHandler`.

## 5. Bản ghi phiên Claude Code

Lệnh (cấu hình MCP tạm, không đụng cấu hình chung của user; mỗi server bọc bằng `tee` để ghi từng dòng vào/ra):

```bash
claude -p "Use the kg-hand MCP find tool to look up 'cong ty abc', then use the kg-rmcp MCP find tool to look up 'duc' with type person. Report the exact id fields returned by each call, nothing else." \
  --mcp-config mcp-config.json --strict-mcp-config \
  --allowedTools "mcp__kg-hand__find,mcp__kg-rmcp__find" --output-format json
```

Vault thử: `Khách hàng/Công ty ABC.md` (`type: client`), `Người/Nguyễn Văn Đức.md` (`type: person`), `.obsidian/Công ty.md` (phải bị bỏ qua).

Kết quả của Claude Code (4 lượt, `is_error: false`, 5,8 s):

```text
- kg-hand: `Khách hàng/Công ty ABC.md`
- kg-rmcp: `Người/Nguyễn Văn Đức.md`
```

Phiên `kg-hand` (`s2-hand`), đủ các dòng; `instructions` và `description` cắt bằng `…` cho gọn, bản đầy đủ khớp chuỗi với Python (test `hand_written_server_handshakes_and_calls_find`):

Nếu một bản Claude Code sau bỏ đường lùi thì Python hỏng trước; khi đó bản Rust theo Python sang giao thức mới (ghi ở Q4: điều kiện xem lại).

Sau phiên không còn tiến trình `s2-hand`, `s2-rmcp` nào chạy (`pgrep`).

## 6. Việc của user: Claude Desktop trên Windows

Cần: Windows có Claude Desktop, Git, và Rust qua [rustup](https://rustup.rs) (bản MSVC; trình cài sẽ đòi Visual Studio Build Tools nếu máy chưa có). `rust-toolchain.toml` ở gốc repo tự kéo đúng bản 1.97.1.

1. Build (PowerShell), sau khi nhánh có `probes/s2-mcp` đã vào `main` (repo private: đăng nhập `gh` trước, hoặc dùng `git clone` với tài khoản có quyền):

   ```powershell
   gh repo clone vantt/obsidian-pkm C:\src\obsidian-pkm
   cd C:\src\obsidian-pkm\probes\s2-mcp
   cargo build --release --features rmcp
   dir target\release\s2-*.exe      # s2-hand.exe, s2-rmcp.exe
   ```

2. Tạo vault thử (không dùng vault thật):

   ```powershell
   $v = "$env:USERPROFILE\kg-probe-vault"
   New-Item -ItemType Directory -Force "$v\Khách hàng", "$v\Người" | Out-Null
   Set-Content -Encoding utf8 "$v\Khách hàng\Công ty ABC.md" "---`ntype: client`n---`nKhách hàng lớn."
   Set-Content -Encoding utf8 "$v\Người\Nguyễn Văn Đức.md" "---`ntype: person`n---"
   ```

3. Thoát hẳn Claude Desktop (cả biểu tượng ở khay hệ thống). Mở `%APPDATA%\Claude\claude_desktop_config.json` (bản Microsoft Store: `%LOCALAPPDATA%\Packages\Claude_*\LocalCache\Roaming\Claude\claude_desktop_config.json`). **Thêm** hai mục dưới vào `mcpServers` sẵn có, giữ nguyên `kg`, `ohs` và các mục khác; thay `<USER>` bằng tên tài khoản Windows:

   ```json
   {
     "mcpServers": {
       "kg-probe-hand": {
         "command": "C:\\src\\obsidian-pkm\\probes\\s2-mcp\\target\\release\\s2-hand.exe",
         "args": ["C:\\Users\\<USER>\\kg-probe-vault"]
       },
       "kg-probe-rmcp": {
         "command": "C:\\src\\obsidian-pkm\\probes\\s2-mcp\\target\\release\\s2-rmcp.exe",
         "args": ["C:\\Users\\<USER>\\kg-probe-vault"]
       }
     }
   }
   ```

4. Mở Claude Desktop, hỏi trong một chat mới:
   - "Dùng tool find của kg-probe-hand tìm 'cong ty abc', cho tôi id nhận được."
   - "Dùng tool find của kg-probe-rmcp tìm 'duc' với type person, cho tôi id nhận được."

   Đúng thì nhận `Khách hàng/Công ty ABC.md` và `Người/Nguyễn Văn Đức.md` (dấu tiếng Việt còn nguyên).

5. Báo lại: hai server có hiện trong Settings → Developer với trạng thái chạy không; hai câu trên trả gì; nếu lỗi thì gửi phần cuối `%APPDATA%\Claude\logs\mcp-server-kg-probe-hand.log` và `mcp-server-kg-probe-rmcp.log` (log chỉ chứa vault thử). Xong thì xoá hai mục khỏi file cấu hình.

Q4 không đổi theo kết quả này trừ khi `s2-hand` hỏng mà `s2-rmcp` chạy được trên Windows.
